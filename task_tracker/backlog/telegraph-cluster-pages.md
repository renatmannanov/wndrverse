# Backlog: Telegraph-страницы для кластеров hot-topics

> Происхождение: обсуждение качества кластеров `/topics` (2026-06-10). Идея
> пользователя: каждой теме дайджеста — своя страница с разворотом треда.
> Формат протестирован вживую, отложено до завершения reply-цепочек
> (план `task_tracker/todo/<reply-chains>/`).

## Идея

Дайджест в DM остаётся коротким списком тем; каждая тема ведёт на
Telegraph-страницу (telegra.ph, официальный инструмент Telegram) с цепочкой
сообщений темы — ССЫЛКАМИ `t.me/c/<chat>/<msg_id>`, НЕ текстами.

## Проверено живым тестом (2026-06-10)

- API живой: `createAccount` + `createPage` работают, один POST без регистрации
  приложения. Тестовая страница: https://telegra.ph/wndr-test-tred-ssylkami-06-10
  (тред лонгрида «уход из компании», 16 ссылок, ноль текстов/имён).
- ✅ С мобильного Telegram t.me/c/-ссылки со страницы открываются в группе.
- ❌ Из Telegram Web t.me/c/-ссылки НЕ работают — ограничение формата, принять
  как известное (аудитория читает с телефона).
- Контент — Node-формат (JSON), лимит ~64 КБ/страница, хватает с запасом.

## PII-контур (главное ограничение)

Telegraph-страницы ПУБЛИЧНЫЕ (любой с ссылкой читает, удалить нельзя — только
затереть `editPage`). Поэтому на страницу кладём ТОЛЬКО:
- название темы (LLM-сгенерированное, без имён),
- список t.me-ссылок (сами сообщения открываются только участникам группы).
НИКОГДА: сырые тексты сообщений, имена, @хендлы.
