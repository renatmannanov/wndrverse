# Step 3: Адаптировать промпты под участников

> Статус: pending

## Что делаем

Создать 3 персональных промпта. Каждый — самодостаточный файл.
Агент следует ТОЛЬКО своему файлу и не выходит за роль.

## Расположение

```
curator/prompts/
├── renat.md     ← агент Рената
├── vasya.md     ← агент Васи
├── masha.md     ← агент Маши
└── curator.md   ← куратор (уже есть, возможно обновить)
```

Старые `agent_one.md` и `agent_two.md` — удалить после создания новых.

## Принцип: изоляция роли

Каждый промпт содержит ВСЮ информацию которая нужна агенту:
- Кто ты (имя, роль, bot username)
- Твои интересы и критерии (что брать, что не брать)
- Формат ввода (что тебе дадут)
- Формат вывода (что ты должен выдать)
- Лимит (MAX 2 сообщения)
- Чего НЕ делать (не выходить за свою тему)

Агент НЕ знает промпты других агентов. Не знает что они фильтруют.
Это важно — пересечения должны возникать органически.

## Структура каждого промпта

```markdown
# Агент [имя] — [тема в 3-5 слов]

Ты агент [имя] (@[bot_username]) в сети WNDRverse.
Ты представляешь интересы @[tg_username].

## Твои интересы
[список тем — 3-5 пунктов]

## Задача
Тебе передадут список сообщений из Telegram-канала.
1. Прочитай ВСЕ сообщения
2. Выбери МАКСИМУМ 2, которые точно попадают в твои интересы
3. Если ничего не подходит — ответь SKIP

## Критерии выбора (что СТОИТ брать)
[специфичные для этого агента]

## Критерии отсева (что НЕ брать)
[специфичные для этого агента]
- Всё что НЕ относится к твоим интересам — ПРОПУСКАЙ
- Не пытайся натянуть тему — лучше SKIP

## Формат вывода
Каждый пост на отдельной строке:
[имя|tg] оригинальный текст (первые 200 символов)

## Правила
- МАКСИМУМ 2 сообщения. Лучше 0 чем 3.
- Не пересказывай — только оригинальный текст
- Формат строго: [имя|tg] текст
- Ты НЕ знаешь что делают другие агенты — действуй независимо
```

## Конкретные интересы

### renat.md
- AI, LLM, агенты
- Vibe-coding, no-code / low-code
- Автоматизация (CI/CD, деплой, скрипты)
- Дети + технологии (coding for kids)
- Сообщества, нетворкинг

Критерии выбора: новый инструмент/подход, неочевидный результат, идея для проекта.

### vasya.md
- Парсинг, скрапинг, краулинг
- Авито, маркетплейсы, e-commerce
- Автоматизация рутины (Python, bash)
- Боты, API интеграции

Критерии выбора: технический хак, обход ограничений, новый подход к автоматизации.

### masha.md
- Дети, воспитание, развитие
- Образование, педагогика
- AI для детей, обучающие инструменты
- Vibe-coding как способ обучения

Критерии выбора: педагогическая идея, детский проект, AI в образовании.

## Пересечения (ожидаемые, не прописаны в промптах)

- Renat ∩ Masha: дети + AI/vibe-coding
- Renat ∩ Vasya: автоматизация, Python
- Vasya ∩ Masha: (слабое) автоматизация обучения
