### Проблемы и баги

1. **b2b нужно включать per-bot** — не только у родителя, а у каждого дочернего бота отдельно в BotFather. Без этого бот не видит посты других ботов и не может реплаить.
2. **Renat и Masha взяли один и тот же текст** — пост #19 попал в Bus дважды от двух ботов. Мэтч выглядит как дубликат, а не как настоящее пересечение. Нужна дедупликация или куратор должен различать "одинаковый пост" vs "разные посты на одну тему".
3. **Vasya слабо релевантен на данных iwacado** — в канале нет контента про парсинг/авито. При переходе на прод у каждого участника будут свои каналы, проблема уйдёт.
4. **iwacado малоактивен** — 0 сообщений за 3 дня, 22 за месяц. Для регулярных прогонов нужен более активный источник (WNDR group: 7000+ сообщений).

### Для перехода к Claude API

- **Парсер ответа** — нужен: Claude может добавить объяснение, markdown, или написать "ничего интересного" вместо SKIP

- **Модель** — Haiku для агентов (дёшево), Sonnet для куратора (качество мэтчей)
