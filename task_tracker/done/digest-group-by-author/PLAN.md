## Контекст (для агента из другого окна — читать первым)

Прод работает: бот `/summary` синтезирует дайджест сообщества через gpt-4o-mini
(`core/brain/synthesis.py`, промпт `core/prompts/digest_synthesis.md`). Имена
авторов НЕ уходят в OpenAI — LLM видит только обезличенные ссылки + тексты, а
настоящие имена подставляются локально из БД (`humanize_refs` в `delivery/cli.py`).

**Проблема (репорт владельца 2026-06-04):** блок «👤 КТО ЧТО» = 1 сообщение → 1
строка. У автора несколько сообщений → имя повторяется (напр. `[Katya Bazyleva]`
×3). Текст сухой и шаблонный («делится опытом и предлагает артефакт» ×15) — это
реестр-перечисление, а не синтез.

## Цель

В блоке «КТО ЧТО»: **1 автор = 1 строка**, где собраны все его мысли/темы за
период. Имена не повторяются. Текст живее (меньше шаблонных повторов).

## Зафиксированные решения (НЕ переобсуждать)

1. **Группировка ПО АВТОРУ — в КОДЕ, до синтеза.** LLM не видит авторов (PII) и
   сам «по человеку» сгруппировать не может. Группируем `selected` фрагменты по
   ключу автора в Pass 2 (`_synthesize_fragments`).
2. **Ключ автора:** `sender_id` если не None, иначе `author_name`, иначе аноним.
   Нумерация `@N` — по порядку ПЕРВОГО появления автора в отсортированном по дате
   списке (детерминированно).
3. **Ссылка на автора = анонимный ключ `[@N]`** (НЕ `[#id]`). LLM получает вход
   вида `[@1] (3 сообщения):\nтекст1\n---\nтекст2\n---\nтекст3`. Пишет `[@1] —
   мысли`. Подстановка `[@N] → [Имя]` локально (маппинг `@N→author` знаем мы).
4. **`[@N]` — ВЕЗДЕ** (ГЛАВНЫЕ ТЕМЫ, КТО ЧТО, НЕ ПОТЕРЯТЬ). Один контракт ссылок.
   Старый `[#id]`-контракт убираем из промпта синтеза.
5. **При имени НЕ показывать дату** — просто `[Имя]` (у автора несколько дат).
6. **temperature синтеза 0.2 → 0.4** (живее, меньше шаблона; имена фиксированы
   промптом — рассинхрона не будет). Отбор (Pass 1) оставить `0.0`.
7. **Модель — gpt-4o-mini** (без изменений; если структура+temp не дадут эффекта
   — про модель решаем ОТДЕЛЬНО, не в этом плане).
8. **PII не ломать:** в OpenAI уходит только `[@N]` + тексты; имена подставляются
   локально.
9. **Pass 1 (отбор >150 сообщений) не меняем по сути:** он остаётся ПЕРЕД
   группировкой (отбор = «какие сообщения важны», группировка = «как показать»).
   После отбора группируем `selected`. Месячные диапазоны (≤150) идут без Pass 1.

## Что уже есть в коде (агенту — не искать заново)

- `core/brain/synthesis.py`:
  - `synthesize(topic, fragments, topic_type)` → `{content, fragment_ids, found,
    model}`. Зовёт Pass 1 (`_select_fragments`) при >150, затем Pass 2.
  - `_synthesize_fragments(topic, topic_hint, fragments)` (стр. ~141): строит
    `fragments_text` как `[#id] (date)\nтекст`, зовёт `complete(temperature=0.2)`.
    СЮДА вводим группировку + `[@N]`.
  - `_select_fragments` (стр. ~103): отбор по `[#id]`, `temperature=0.0`. НЕ трогаем.
- `core/prompts/digest_synthesis.md`: промпт. Уже есть правила (безличные формы,
  не выдумывать имена, ссылка подлежащим). Переписать под `[@N]` + «1 автор = 1
  строка» в КТО ЧТО.
- `delivery/cli.py`:
  - `humanize_refs(content, fragment_ids)` (стр. ~81): `[#id] → [Имя, дата]` через
    `get_fragments_by_ids`. Регэксп `_REF_RE = r"\[?#?(\d+)\]?"`.
  - `build_digest(topic, since, until)` → `{text, found, used}`: зовёт
    `synthesize_and_save` + `humanize_refs`. Scheduler зовёт `build_digest` —
    НЕ ломать сигнатуру/возврат.
- `core/store/fragments_db.py`: `get_fragments_for_digest` возвращает каждый
  фрагмент с `id, text, created_at(str ISO), author_name, sender_id, tags`.

## Критерии готовности

- [ ] Pass 2 группирует `selected` по автору; LLM получает вход с `[@N]` и
      текстами одного автора вместе; имена в промпт НЕ попадают (PII).
- [ ] `synthesize` возвращает маппинг `author_refs: {N: имя}` (имя из БД);
      `build_digest` подставляет `[@N] → [Имя]` локально (без даты), старый
      `humanize_refs`-вызов УДАЛЁН (не оба).
- [ ] PII в логах: `author_refs`/`result` не логируются (имён нет в journalctl).
- [ ] В готовом дайджесте каждое имя встречается в блоке «КТО ЧТО» НЕ БОЛЕЕ
      одного раза (нет `[Имя]…[Имя]…[Имя]` для одного автора).
- [ ] temperature синтеза = 0.4; отбор = 0.0.
- [ ] Прогон на `commits 2026-05-16..31` (локально): «КТО ЧТО» — по автору, без
      повтора имён, текст не шаблонный; имена не отправлены в OpenAI.
- [ ] `pytest tests/ -q` зелёный; scheduler (`build_digest`) не сломан.
- [ ] Задеплоено на VPS, бот перезапущен, прод-smoke владельцем прошёл.
