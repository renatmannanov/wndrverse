### Решения (зафиксированы с пользователем)
- Граница = вариант А (внутри топика). Б/С — out-of-scope.
- Якорь ссылки = ВСЕГДА первое по времени сообщение кластера (НЕ самое
  залайканное — оно может быть в конце треда). Лайки только для ранга.
- Формула ранга: нормированный `0.5*msgs + 0.3*likes + 0.2*authors`, веса
  фиксированы в hotness.py (ранг вторичен, не вылизываем).
- Уникальные авторы — по sender_id distinct, None-авторы (анонимы) не считаются.
- Зацеп: LLM даёт короткое русское НАЗВАНИЕ темы; фактическая цитата = якорное
  сообщение (по ссылке). (В MVP-рендере показываем название+ссылку; саму строку-
  цитату в тексте можно не печатать — ссылка ведёт в неё.)
- Названия тем — по-русски.
- Лимит тем — настраиваемый --limit, дефолт «все прошедшие фильтры».
- Прототип на boltalka. Команда: `python -m delivery topics --topic X --period Y`.

### Качество кластеров (главный приоритет) — 3 слоя фильтрации
1. ВХОД (до кластеризации): min_chars + `_is_substantive` (мало уникальных слов /
   почти одни эмодзи) — режем флуд ДО HDBSCAN.
2. HDBSCAN: noise (-1) не показываем; min_cluster_size = тема ≥ N сообщений.
3. ВЫХОД: min_authors (тема ≥2 человек), min_probability (рыхлые точки).
Пороги калибруются на шаге 7, финал фиксируется в коде.

## Learnings

### Ревью плана (2026-06-09, review-plan скилл) — применено
План прошёл параллельное ревью (code/risks/structure/coverage). Покрытие 100%.
Применены правки реализации в step-файлы:
- step_1: reactions лежит в JSONB `metadata_['reactions']` (НЕ отдельная колонка);
  доступ с `.label('reactions')`, проверить list vs str (json.loads если str).
  Добавлен кейс until=None.
- step_2: `fit_predict` НЕ даёт probabilities — заменено на `fit()` +
  `.labels_`/`.probabilities_`.
- step_4: переписан единый контракт TopicCluster (БЕЗ поля emoji — эмодзи
  назначает рендер по позиции). Убрана «поправка по ходу».
- step_5: anchor = `min(members, key=created_at)` (НЕ members[0] — группировка по
  label не сохраняет порядок). min_probability отсекается ДО cluster_stats. PII:
  в промпт только `f['text']`. topic_label.md добавлен в критерии.
- step_6: добавлена ветка диспетчера `elif args.command == "topics"`; при 0
  фрагментов/тем печать в STDOUT (не только лог); guard на --topic all.
- step_7: предупреждение про дороговизну --period all.

«Зацеп=цитата» — сознательно НЕ в MVP (ссылка ведёт в якорь). Если заказчик
попросит цитату текстом — мелкая доработка рендера, отдельно.

### Реализация (2026-06-09) — шаги 1–7 done
Все шаги выполнены последовательно в одном окне. 13 юнит-тестов зелёные
(hotness/cluster_core/topics_render/topics_build). PII чисто (grep topics.py:
в промпт topic_label уходит только f['text']).

**Баг найден на калибровке (шаг 7) и починен:** UMAP spectral init падает
(`scipy eigsh: k >= N`) на узком срезе (1w boltalka = 3 фрагмента после фильтра).
Фикс в `cluster_embeddings`: для малых входов (`n <= 4*n_components`) переключаем
UMAP на `init='random'` — стабилен на малых, корпусной путь (тысячи векторов)
остаётся на spectral. Тот же degenerate-кейс ловился в юнит-тесте монолога.
