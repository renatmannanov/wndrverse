## Что остаётся открытым (закрывается прагматично в step_2)

Эти вопросы практические — закрываем когда упрёмся в них при написании `main.py`. Не блокируют старт step_2.

- **Q1 (доустановка):** точная установка `claude-agent-sdk` для Python и минимальный пример вызова session — выяснится в первом рабочем `main.py`
- **Q2 (поведение OAuth vs API key):** что делает SDK если в env есть и `ANTHROPIC_API_KEY`, и активная OAuth-сессия. **Защитная мера в step_2:** просто **не класть** `ANTHROPIC_API_KEY` в `.env` агента Клода (PLAN.md фиксирует это как правило)
- **Q3 (формат allowed_tools):** в Python SDK — выяснится при первом вызове. Стартовое решение: **никаких tools** не давать вообще, контекст подавать в промпт
- **Q5 (hard-timeout):** реализуем через `asyncio.wait_for(main(), timeout=300)` — встроенным или внешним обвернём, что окажется проще
- **Q6 (rate limit error class):** какие именно exception-классы кидает SDK при weekly cap — узнаем из docstring/source при импорте; обернём `try/except Exception` для MVP, специфический catch добавим когда увидим конкретный класс
