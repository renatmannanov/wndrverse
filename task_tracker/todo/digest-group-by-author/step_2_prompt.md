# Шаг 2: Переписать промпт под [@N] + «1 автор = 1 строка»

> Зависит от: шаг 1 (вход уже сгруппирован по автору, ссылки [@N])
> Статус: [ ] pending

## Задача

⚠️ Правишь ТОЛЬКО `core/prompts/digest_synthesis.md` (промпт синтеза, Pass 2).
Файл `core/prompts/digest_selection.md` (промпт отбора, Pass 1) НЕ ТРОГАЕШЬ — у
него свой контракт (`[id]` для выбора сообщений), он не конфликтует с `[@N]`.

Переписать `core/prompts/digest_synthesis.md` так, чтобы LLM:
- понимал новый контракт: `[@N]` = один УЧАСТНИК (не сообщение), под ним собраны
  все его сообщения за период;
- в блоке «КТО ЧТО» давал **одну строку на участника** со всеми его мыслями;
- ссылался строго через `[@N]` (везде), не выдумывал имена, писал безлично.

### Что меняется в промпте

Сейчас правила говорят про `[#ID]` = сообщение. Переписать на `[@N]` = участник.

Ключевые формулировки (адаптировать существующий текст, НЕ переписывать весь файл
с нуля — сохранить структуру 3 блоков и лимит символов):

1. Вход описать так: «Тебе дан список участников. Каждый помечен `[@N]` — это
   ОДИН участник. Под ним собраны все его сообщения за период (через `---`).»
2. Блок «👤 КТО ЧТО» — явно: «по КАЖДОМУ участнику ОДНА строка: что он
   предлагает / просит / исследует / завершил — собери все его мысли вместе.
   Начинай строку с `[@N]`. НЕ создавай несколько строк на одного `[@N]`.»
3. Правила ссылок (заменить старые про `[#ID]`):
   - «Ссылайся на участников строго `[@N]` — теми номерами, что во входе. НЕ
     придумывай номера. Имя подставит система.»
   - «НИКОГДА не пиши имена/ники/«Коля»/«участник» — только `[@N]`.»
   - «`[@N]` — ПОДЛЕЖАЩЕЕ. Безлично, настоящее время, без родовых форм:
     `[@1] — предлагает вести дневник`, не `[@1] предложил/предложила`.»
4. Блоки «📌 ГЛАВНЫЕ ТЕМЫ» и «⭐ НЕ ПОТЕРЯТЬ»: ссылки на участников тоже `[@N]`
   (один контракт). Темы группируют по смыслу, со ссылками `[@N]` на участников.
5. Сохранить: 3 блока (ГЛАВНЫЕ ТЕМЫ / КТО ЧТО / НЕ ПОТЕРЯТЬ), лимит ~3500–4000
   символов, «не выдумывай факты», «на русском, по делу».

⚠️ Плейсхолдер в промпте остаётся `{fragments_text}` (шаг 1 кладёт туда
сгруппированный текст) + `{topic}`, `{topic_hint}`. Не вводить новых плейсхолдеров.

## Тесты

Промпт текстовый — юнит-тесты не на него, а на поведение (шаг 1 уже покрывает
группировку/подстановку). Здесь проверка — реальный прогон (см. команды).

Добавить тест (ОБЯЗАТЕЛЬНЫЙ, регресс-страховка от старого контракта):
`digest_synthesis.md` содержит `[@`-инструкции и НЕ содержит `[#ID]`/`[#id]`.
Это `assert "[@" in prompt and "[#ID]" not in prompt and "[#id]" not in prompt`
на загруженном файле.

- безличные формы (нет «предложил/предложила»);
- нет сырых `[@N]` в выводе (подстановка отработала из шага 1).
