# Progress Log — digest-group-by-author

## Контекст для агента

- Цель: блок «КТО ЧТО» в дайджесте — 1 автор = 1 строка (все его мысли вместе),
  имена не повторяются, текст живее. Причина: сейчас 1 сообщение = 1 строка →
  повтор имён + шаблонный сухой текст (репорт владельца 2026-06-04).
- PII — главное ограничение: имена авторов НИКОГДА не уходят в OpenAI. LLM видит
  только `[@N]` (анонимный ключ автора) + тексты. Имена подставляются ЛОКАЛЬНО из
  БД после синтеза. Не нарушить это.
- Контракт ссылок меняется: было `[#id]` (на сообщение), стало `[@N]` (на автора).
  `[@N]` ВЕЗДЕ (все 3 блока). Старый `[#id]`-путь в промпте убирается.
- Подстановка: НОВАЯ `humanize_author_refs(content, author_refs)` в delivery/cli.py
  (старую `humanize_refs` не удалять — оставить). `author_refs: {N: имя}` приходит
  из `synthesize()`.
- temperature синтеза 0.2 → 0.4 (живее). Отбор (Pass 1) остаётся 0.0.
- Группировка по автору — в КОДЕ (`_group_by_author` в synthesis.py), до Pass 2.
  Ключ автора: sender_id → author_name → аноним. Нумерация @N по дате 1-го сообщения.
- Pass 1 (отбор при >150) НЕ трогать по логике: отбор ДО группировки. Месячные
  диапазоны (≤150) идут без Pass 1 — это типичный случай.
- Модель остаётся gpt-4o-mini. Про смену модели — отдельно, НЕ здесь.
