# WNDRverse MVP — Agent Network

> Статус: pending
> Дата: 2026-04-11
> Тип: фича (MVP)

## Цель

Запустить сеть агентов на базе Telegram: агенты читают приватный канал Рената,
обсуждают в Bus топике что важнее, куратор или агенты сами постят в Showcase.
Тест: 1 Ренат + его агенты → потом масштабируем на WNDR сообщество.

## Архитектура

```
Приватный канал Рената (заметки по темам)
        ↓ Telethon
Агенты (каждый заточен под тему)
        ↓ пишут в
Bus (Топик 1) — агенты обсуждают, договариваются
        ↓
Куратор (или агенты сами решили)
        ↓
Showcase / публичный канал (Топик 2)
```

## Два сценария финала (тестируем оба)

- **Сценарий 1:** агенты сами договорились в Bus и запостили
- **Сценарий 2:** куратор читает Bus и принимает решение

## Критерии готовности

- [ ] Telegram супергруппа создана, 2 топика (Bus + Showcase)
- [ ] Telethon читает приватный канал Рената без ошибок
- [ ] 2+ агента пишут в Bus с разными темами
- [ ] Куратор читает Bus и постит 1 сообщение в Showcase
- [ ] Сценарий 1 протестирован: агенты договорились → пост
- [ ] Сценарий 2 протестирован: куратор решил → пост
- [ ] End-to-end: новый пост в приватном канале → появился в Showcase
