# Полнота тем: /topics с интригой + /summary с содержанием тем

> Статус: pending
> Дата: 2026-06-18
> Тип: фича (качество вывода)

## Цель

Сделать «темы полнее» в ДВУХ режимах дайджеста РАЗДЕЛЬНО (не смешивая их):
1. **`/topics`** (hot-topics) — к каждой теме добавить ОДНУ цепляющую строку-интригу
   (крючок: вопрос/конфликт/неожиданная развязка — НЕ пересказ), чтобы читателю
   хотелось тыкнуть ссылку. Название + интрига генерятся ОДНИМ LLM-вызовом.
2. **`/summary`** (people-digest) — блок «📌 ГЛАВНЫЕ ТЕМЫ» сделать С СОДЕРЖАНИЕМ
   (1–2 предложения сути на тему вместо голой формулировки). Блоки «👤 КТО ЧТО»
   и «⭐ ЗАПРОСЫ И ПРЕДЛОЖЕНИЯ» НЕ трогаем.

## Видение результата

- `python -m delivery topics --topic boltalka --period 1m` → каждая тема:
  `эмодзи + название + (N сообщений)` / строка-интрига / ссылка t.me.
- `python -m delivery digest --topic <...> --period 1m` → в блоке ГЛАВНЫЕ ТЕМЫ
  каждая тема с 1–2 предложениями сути; остальные блоки без изменений.
- PII-контракт цел: в OpenAI уходят только тексты сообщений / `[@N]`, имена и
  sender_id подставляются локально.
- Юнит-тесты зелёные; golden-set осознанно переснят (snapshot — PII, gitignored).

## Out-of-scope

- НЕ смешиваем два режима в один вывод.
- НЕ трогаем «КТО ЧТО», «ЗАПРОСЫ», кластеризацию, hotness, anchor-логику,
  Pass-1 selection, критика.
- НЕ добавляем блоки «Ссылки из чата» / «Что рекомендовали» (другой профиль
  контента, отдельная задача).
- НЕ трогаем прод (на gpt-4o-mini из-за TPM-инцидента) — обкатка ТОЛЬКО локально.
- НЕ деплоим на VPS в рамках этого плана (деплой — отдельной командой после показа).

## Критерии готовности

- [ ] `/topics`: вывод содержит строку-интригу под названием каждой темы;
      при пустой/ошибочной интриге тема рендерится как раньше (название+N+ссылка),
      рендер не падает. Проверено локально на boltalka.
- [ ] `/summary`: блок «📌 ГЛАВНЫЕ ТЕМЫ» содержит 1–2 предложения сути на тему;
      блоки «КТО ЧТО» и «ЗАПРОСЫ» структурно не изменились.
- [ ] PII: ни в одном новом промпте нет имён/`@handle`/sender_id — только текст / `[@N]`.
      Проверено чтением промптов (grep) и тестом синтез-промпта.
- [ ] Юнит-тесты зелёные: `python -m pytest -q` (особо: test_topics_render,
      test_topics_build, test_synthesis_prompt).
- [ ] Длина вывода `/summary` не превышает прежний жёсткий потолок (≤3500 в
      промпте, реальный текст после подстановки имён < 4096).
- [ ] Golden-set переснят и diff просмотрен глазами (улучшение, не регрессия).
