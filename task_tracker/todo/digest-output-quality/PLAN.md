# Улучшение качества вывода саммари (digest)

> Статус: pending
> Дата: 2026-06-18
> Тип: фича + фикс (качество вывода)

## Цель

Поднять качество вывода дайджеста (`build_digest` → `/summary`, scheduler, CLI):
убрать обрывы текста, поднять recall коротких офферов/запросов, перейти на более
сильную модель синтеза, добавить контроль дефектов (self-критик) и защиту от
регрессий (golden set). Фокус — КАЧЕСТВО ВЫВОДА САММАРИ. Hot-topics (`/topics`)
пайплайн НЕ трогаем.

## Видение результата

- `build_digest` на тех же входах даёт более полные саммари без обрывов на полуслове.
- Синтез (Pass-2) идёт на `gpt-4o` (настраивается через `WNDR_SYNTHESIS_MODEL`);
  селекция (Pass-1) остаётся на `gpt-4o-mini`.
- Короткие (80–149 симв.) офферы/запросы больше не выпадают из дайджеста.
- При включённом флаге `WNDR_DIGEST_CRITIC` в логах синтеза видны warning'и
  self-критика о дефектах (обрывы, выдуманные `[@N]`, путаница «кто что»,
  родовые формы) — текст при этом НЕ переписывается. По умолчанию критик ВЫКЛ
  (без доп. вызовов OpenAI в обычном проде).
- Есть `python -m tests.golden.run` — прогоняет фиксированные кейсы через
  `build_digest` и показывает git-diff снапшотов (ручная регрессия вывода).
  Перед правками снимается baseline (`--baseline`) для сравнения эффекта плана.

## Out-of-scope

- НЕ чиним асинхронный дедуп (`is_duplicate` отстаёт до 6ч — known limitation,
  только задокументировать в progress.md, см. шаг 4 / общий контекст).
- Self-критик НЕ переписывает текст (авто-починка — будущий флаг, не сейчас).
- LLM-judge для golden set — не сейчас (только snapshot-режим).
- Structured-output (JSON-вывод модели) — отдельная большая правка, не здесь.
- `/topics` (hot-topics) пайплайн не меняем.
